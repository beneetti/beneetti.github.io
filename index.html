AI VJing Tool

An innovative audio-visual performance tool that leverages AI to create dynamic, real-time visualizations synchronized with music. The project involved developing a Stable-Diffusion Plugin, paired with a granular Audio Analysis component within Touchdesigner. Dynamic AI images are created via Text to image and image to image prompts.

The project involved creating an intuitive user interface, optimizing workflow efficiency, and integrating advanced features for seamless workshop management. Since the tool is currently in use, specific details about the project are confidential, but it represents a significant achievement in enhancing operational efficiency and user experience for BMW's workshop planning processes.

Alte Pinakothek - Nature into Art

Immersive AI Driven Exhibition - Full-Stack Development of an AI-based, interactive Art Installation. The project involved creating multiple prototypes based on different UX design techniques to create an immersive exhibition experience that transforms natural elements into artistic expressions using AI technology, motion/sound tracking, and sensor integration. The installation allows visitors to interact with the artwork, creating a dynamic and engaging environment that blurs the line between nature and art. It represents a significant achievement in combining creative UX design with advanced programming to deliver a unique cultural experience at the Alte Pinakothek.

WaveLab - Motion Based Sound Control Tool for Ableton Live

A motion-based sound control tool for Ableton Live, designed to enhance music production and live performance. The project involved developing a custom software solution that allows musicians to manipulate sound parameters in real-time using body movements. The tool integrates with Ableton Live, providing an intuitive interface for controlling various aspects of the music, such as volume, effects, and tempo, through motion tracking technology. This project demonstrates a successful fusion of creative UX design and programming to create an innovative musical experience.

Public Interface - ExPresso

A public interface for a smart coffee machine, designed to enhance user experience through intuitive controls and real-time feedback. It features facial expression recognition to order drinks, depending on different mood states. The project involved creating a user-friendly interface that allows users to customize their coffee preferences, view brewing status, and receive maintenance notifications. The design focuses on simplicity and accessibility, ensuring that users of all ages can easily interact with the machine. This project demonstrates a successful integration of UX design principles with practical functionality in a consumer product.

BeamTogether - An UX Design Project

Full-Stack Development of an App and Hardware Prototype for weekly Meetings over Distances via a Mood Lamp, simulating a real time sunset together. The project involved creating an intuitive user interface for the app, designing the hardware prototype, and integrating both components to provide a seamless user experience. The app allows users to schedule virtual meetings, customize their mood lamp settings, and share moments together despite physical distance. This project showcases a successful blend of creative UX design and technical development to foster connection and togetherness through innovative technology.
